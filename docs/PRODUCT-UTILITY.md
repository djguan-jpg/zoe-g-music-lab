## 一般介面只保留三條流程

1. **字幕交付**：匯入 SRT／LRC／本工具歌詞 JSON，預覽後套用，核對時間並建立標準字幕、文字 JSON 與格式報告。不能在本頁補寫或修訂句子；有問題時在原工具修正後重匯入。
2. **音檔核對**：選擇 PCM WAV 與示範收件條件，讀取規格、音量與削波風險，下載報告。不能修音或轉檔；尚未量測 true peak。
3. **素材交接**：開啟本工具 `.zoemv.json`，核對原音檔、圖片與文字，再保存或下載 Agent 純文字企劃。不是 CapCut、Kdenlive 或 DAW 原生專案匯入器；Agent 修訂仍需要文件中的明確本機指令。

舊編輯元件與契約保留在隱藏容器，沒有一般介面的重新啟用按鈕。載入舊專案或切換流程不能讓編輯區重新出現。頁面不再自動填入示範企劃。

## 後續功能的實用性門檻

新增工作先寫清楚「哪一個人、哪一件實際作品、目前在哪一步卡住、既有工具為何不夠」，再比較成熟工具的現有做法。沒有具體工作與輸出，就先做研究或小型驗證，不建立另一套通用編輯器。

優先驗證一件真實作品的跨工具交接：在原工具完成編輯 → 匯入字幕與本工具素材專案 → Agent 修訂 → 核對素材保留 → 交付原工具可接續的檔案。以實際花費時間、人工步驟、修正次數與成果能否接續衡量，不能把版本數、模組數或測試數當成使用價值。

本輪只用自有合成資料證明流程可執行。尚無真實創作者使用成效、第三方剪輯工具實際開啟接受或市場需求證據；「交接與核對值得做」仍是待驗證的產品假設。若真實流程沒有省事，繼續縮減或調整方向。
