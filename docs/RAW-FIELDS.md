# 原值欄位與未完成草稿

從 v0.33 開始，尚未完成的數字（例如 `4e`）、全形數字、前後留白與未知畫幅都可保留在 draft3。這讓你先記下想法，再修正待辦。保存草稿不代表資料已可產生完整成果。

數值欄位使用文字輸入與 decimal 鍵盤提示，原有歌曲範圍、歌詞毫秒、分鏡秒數／影格／連戲仍由原診斷及完整 domain 檢查。畫幅原值不在選單時顯示「原值需核對」，可明確選擇支援畫幅；不會自動改成第一個選項。

瀏覽器會改寫部分字元，例如單行輸入中的換行、textarea 中的 CR。工作台會顯示可見的 `\r`／`\n`／`\u0000` 等符號及保留提示。未編修時，另存草稿與原欄位報告取原字串；你編修該欄後，新的文字成為原值，提示消失。工作台不把你輸入的反斜線文字自動解碼。原 JSON 檔請保留。

## 分層

| 層 | 責任 |
| --- | --- |
| `web/raw-fields.js` | 以 opaque control 為 key 的 WeakMap，分開原字串與顯示字串；bind／capture／edited。沒有 DOM、數值解析、I/O 或持久存檔。 |
| `web/raw-fields-dom.js` | 控制項寫入／讀取、未知 select 選項、特殊字元提示與 aria-describedby；明確 input 事件採新文字。選項與提示使用 textContent。 |
| `web/app.js` | 同一 adapter 串接全域欄位、段落、需求、母題、鏡頭、歌詞列；載入、草稿庫、另存、報告與可還原編修都使用 capture。 |
| 現有 readiness／domain／application | 只驗證需要完成的資料，維持十進位／範圍／秒數與影格規則；完整建立可拒絕已保存的未完成草稿。CLI／HTTP／Agent／MCP仍共用 application。 |

渲染列後再次 bind 原字串，避免 HTML parser 先改寫 NUL 或換行。沒有把原值副本序列化到額外的 DOM dataset；暫態 WeakMap 不會另開網路、不讀素材、不授予登入或產生 AI 呼叫。移除列後不以長期 row map 保留控制項。

## 版本與使用界線

產品版本0.33、草稿schema3、Agent protocol1、music_review／storyboard_review schema1各自管理；沒有遷移、工具或依賴增加，基本9工具／明確啟用草稿庫14工具保持。未知schema仍拒絕。

草稿來源逐值保留；JSON縮排、換行、保存時間或工作台tab可依另存更新，因此不宣稱來源檔案 bytes 相同。完整成果會依既有 domain 作數值與文字正規化，成果來源契約與「未完成草稿」分開。整份草稿載入仍明確替換工作台並需重選音檔；限定接續與原有撤回界線保持。

分鏡待辦只檢查必填、畫面方向及母題引用。零待辦的 FPS／時間仍可能無效，必須完整建立驗證。歌詞採既有 ASCII 十進位與毫秒契約；保留非標準字串不授予其有效時間身分。實唱、實聽、實際畫面、素材權利及平台審核由人完成。
