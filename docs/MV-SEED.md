# 隱藏編輯元件的重新起稿契約

本輪初始重現：載入素材專案後，上方名稱與歌詞仍為預設值；原「建立試播草稿」立即替換已編修歌詞與圖片。這項修正已完成，之後依使用者要求將整個編輯區隱藏；不把它當新產品功能推廣。

`web/mv-seed.js` 為純控制器，DOM adapter 負責原生讀取與寫入，app 只在完整載入草稿後同步起稿欄位。預覽不寫入；確認建立才替換。預覽綁定原稿、列 ID、媒體來源與可用性、原生音檔 File 身份、原始名稱／歌詞、文字卡選擇及圖片 File 身份。編修、換檔、來源失效或取消後，不復活舊提案。

未重選圖片時沿用原附件；明確「只使用文字卡」才移除圖片。預覽說明逐句修訂、時間、母題與鏡頭創作會被重建。確認後逐份回讀實際稿件、列 ID、音檔與圖片 SHA-256；拒絕、無動作、部分寫入或不符回讀不報成功，不自動重試或回滾。

純控制器 7 項、實際 DOM adapter／原 app 載入及舊版專案重開 8 項測試覆蓋保留、失效與拒絕。原生 Chrome 合成資料另驗預覽／取消原欄位保留、圖片接續、保存下載與重開；這不是實聽、精準音訊裁切或真實作品接受。

一般介面不顯示這些編輯操作，見[實用性取捨](PRODUCT-UTILITY.md)。既有 Agent、草稿及素材專案契約保持。
