# v0.3.0 驗證證據

本輪流程：`http://127.0.0.1:8875/` → 歌詞讀取／刪改 → 即時播放預覽；專案草稿下載 → 回讀 → 撤回／錯誤版本拒絕。使用 IAB 與已知合成案例，沒有正式作品或使用者其他專案。

## 重現與修正

v0.2 中刪除第一句後表格剩三句，第一列為「紙箱裡裝不下那句話」，播放預覽仍顯示被刪的「空房剩一圈淡色的牆」。v0.3 重跑相同步驟後預覽為省略號；再把新首句開始改為 0、文字改成「本輪即時編修」，預覽立即更新，舊成果下載仍停用。

舊音檔晚完成解碼會覆寫新波形的競態，以可控 Promise 先完成新任務、再完成舊任務驗證；結果維持新波形。瀏覽器另實跑 60 秒音檔切換 1 秒音檔，顯示 1.000 秒且波形完成。此普通切換不能單獨證明所有實際瀏覽器解碼排程，故保留競態回歸測試。

## 自動與封裝驗證

44 項 Python 測試涵蓋既有四 CLI、HTTP、領域數值、Agent 真正子程序、異常 request 後繼續執行、音檔保持、授權 routes；4 項 JavaScript 測試涵蓋最新任務競態、歌詞播放區間及草稿契約。

封裝只能使用指定 Git commit。包內測試由 scripts/package_release.py 在暫存解壓目錄執行；ZIP、commit、SHA-256、每檔摘要及結果放在同目錄 manifest.json。不得用這份說明或工作區測試替代實際 manifest 的檢查結果。
