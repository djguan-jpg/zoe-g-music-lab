# 分鏡總長與鏡尾（v0.27.0）

新增鏡頭保留作品宣告總長。例如原宣告60秒、目前四鏡覆蓋24秒，新增第五鏡24–30秒後仍宣告60秒，另顯示30秒鏡尾。刪除鏡頭仍依既有規則收合剩餘時間，保留宣告；刪除還原保護後續編修，不自動替換總長。時間與宣告不同時，核對後明確按「採用鏡尾為總長」，或手動修改。

## 核對與撤回

純proposal讀取目前全部鏡頭的原始開始／結束字串、列身份及FPS。最多1000鏡；拒絕空白、非有限、負值、顛倒、超範圍、秒數重疊／空缺及影格不連續或少於一幀。沿既有秒數容差0.001與nearest ties-to-even影格規則；容差不能掩蓋影格錯誤。鏡尾需為0–14400秒內正數，FPS為0–120內正數。這只核對時間覆蓋，不檢查未完成的創作欄位或證明實際音畫同步，仍須完整建立驗證。

採用只寫入原始最後結束字串，沒有取最大值、猜時長、捨入秒數或修改FPS。例如24.0004秒及29.97FPS維持原值。空白、錯誤或不同的宣告保持原樣，直到明確採用。相同宣告停用採用按鈕；不可用的時間顯示原因。

注入controller以同一快照產生顯示及可採用來源，採用前重查原始來源與顯示快照。撤回保存原宣告及實際寫入後值，只還原總長。後續畫面／運鏡／母題／人物等文字保留；任一時間、列身份／順序／數量、FPS或接續後總長不同時拒絕撤回。回到相同原始來源與接續後值可再撤回。原創範例、完整草稿或限定分鏡需求載入會清除暫態紀錄，不從草稿復活它。處理中停用採用／撤回，新增鏡頭也拒絕重複工作。

刪除還原與總長撤回分開。如果刪除後採用較短鏡尾，再還原鏡頭，新的總長保持；需重新核對鏡尾及完整分鏡。音檔、歌曲、歌詞、素材與刪除歷史不由總長操作修改。

## 分層與跨工具

web/storyboard-duration.js是無DOM／I/O／網路的純proposal／compare與注入controller，重用storyboard-frames影格層。app讀取原始欄位與既有列ID、呈現比較、限定寫入及dirty；資料處理仍由application與領域驗證負責。總長接續沒有新增模型、依賴、Agent operation或schema。

產品0.27.0；Agent1／MCP2025-11-25／draft3及各領域schema保持，七預設／啟庫十二工具。Agent／CLI讀回的現代需求先核對預覽，再明確載入；payload的總長仍由呼叫者明確指定，application不自行用鏡尾覆蓋它。60秒宣告卻只有24秒完整鏡頭仍拒絕；明確採用24秒後，四adapter可建立同一成果。暫態總長記錄與原生媒體身份不進草稿、wire或Git。
